# Bybit Premium Terminal v1.0

Добро пожаловать в профессиональное рабочее пространство трейдера. Данный терминал спроектирован для мгновенного пре-трейд расчета рисков, автоматического контроля маржинальных параметров биржи Bybit и ведения интеллектуального торгового дневника.

## ⚡ Инструменты инжекции цен и скальпинг-интерфейс

Информер терминала подключен к прямому биржевому потоку Bybit через высокоскоростной протокол WebSocket (канал `orderbook.1`). Вы можете мгновенно переносить ликвидные котировки из стакана в калькулятор в один клик:

- **Клик по центральной цене (Mid Price):** Вычисляет среднюю точку между лучшим Ask и лучшим Bid: `(Ask + Bid) / 2`. Автоматически устанавливает её в поле «Цена входа», запускает перерасчет математического ядра и копирует чистое числовое значение в буфер обмена.
- **Клик по кнопке Ask (Красная):** Мгновенно инжектирует цену лучшего лимитного ордера на продажу из стакана Bybit в калькулятор. Идеально для мгновенного расчета входа в Шорт маркет-ордером или установки Лимитного Лонга на уровень Ask.
- **Клик по кнопке Bid (Зеленая):** Мгновенно инжектирует цену лучшего лимитного ордера на покупку из стакана Bybit в калькулятор. Идеально для быстрого расчета входа в Лонг маркет-ордером или установки Лимитного Шорта на уровень Bid.

## 📈 Спецификация и формулы: Фьючерсный режим (Linear Perpetual)

Фьючерсный калькулятор полностью воссоздает логику маржинального движка Bybit V5 для линейных контрактов (USDT). Выделенный объем позиции жестко привязан к правилу: `Cost = Deposit / 5` (под одну сделку изолированно выделяется ровно 20% от текущего баланса, оставляя 80% в качестве резервного обеспечения аккаунта).

### 1. Расчет рабочего плеча на основе волатильности (ATR Filter)

Плечо не выбирается случайным образом, а динамически масштабируется под текущую волатильность инструмента, чтобы защитить позицию от случайного выноса рыночным шумом. За эталон взята базовая волатильность `0.025 (2.5%)`.

- **Формула расчета плеча:**
  `Leverage = Max(1, Min(100, Round(BaseLeverage * (0.025 / ATR))))`
- **Пример:** Для BTCUSDT при `BaseLeverage = 20` и текущем `ATR = 0.025` плечо составит: `20 * (0.025 / 0.025) = 20x`. Если волатильность вырастет до `0.05` (5%), плечо автоматически снизится: `20 * (0.025 / 0.05) = 10x`.

### 2. Расчет объема позиции (Value) и количества монет (Qty)

- **Формула общего объема позиции (Value в USDT):**
  `Total Volume = Cost * Leverage`
- **Формула количества контрактов (Qty в монетах базового актива):**
  `Qty = Total Volume / Entry Price`
- **Пример:** Баланс `$100`, Цена входа BTC = `$79,670`, Плечо = `20x`.
  `Cost = 100 / 5 = $20`
  `Total Volume = 20 * 20 = $400.00 USDT`
  `Qty = 400 / 79,670 = 0.00502 BTC` (округляется по правилам `qtyDecimals`).

### 3. Сверхточный расчет уровней Стоп Лосс (SL) и Тейк Профит (TP)

Формула полностью учитывает асимметрию биржевых комиссий Bybit на вход и выход.
Заложенные комиссии: `Taker Fee = 0.055%` (рыночный ордер), `Maker Fee = 0.020%` (лимитный ордер).
Обозначения в формулах: `rPct = RiskPercent / 100` (например, 0.02 для риска 2%), `R` = Соотношение Risk/Reward (P/R Ratio от 1 до 5).

#### Направление LONG (Покупка):

- **Формула Стоп Лосс (SL):**
  `SL = Price_Entry * ((1 - rPct / Leverage - Fee_Entry) / (1 + Fee_Exit_SL))`
- **Формула Тейк Профит (TP):**
  `TP = Price_Entry * ((1 + (R * rPct) / Leverage + Fee_Entry) / (1 - Fee_Exit_TP))`

#### Направление SHORT (Продажа):

- **Формула Стоп Лосс (SL):**
  `SL = Price_Entry * ((1 + rPct / Leverage + Fee_Entry) / (1 - Fee_Exit_SL))`
- **Формула Тейк Профит (TP):**
  `TP = Price_Entry * ((1 - (R * rPct) / Leverage - Fee_Entry) / (1 + Fee_Exit_TP))`

### 4. Расчет Цены Ликвидации (Liq Price)

Терминал рассчитывает цену принудительного закрытия для Изолированной маржи по правилам Bybit, закладывая нормативную маржу поддержания позиций `MMR = 0.4% (0.004)`.

- **Ликвидация LONG:** `Liq = Price_Entry * (1 - 1 / Leverage + MMR)`
- **Ликвидация SHORT:** `Liq = Price_Entry * (1 + 1 / Leverage - MMR)`

## 🪙 Сквозной математический пример расчёта (Фьючерсы BTCUSDT)

#### Исходные параметры трейдера:

- **Депозит ордера (DEP):** `$100.00`
- **Торговая пара:** `BTCUSDT`
- **Выбранный риск:** `2%` (Сумма потери: `riskAmount = $2.00`)
- **P/R Ratio:** `1 : 3` (Целевая прибыль: `$2.00 * 3 = $6.00`)
- **Тип ордера:** Рыночный (`market` -> `Fee_Entry = 0.00055`)
- **Выход по SL/TP:** Рыночный (`market` -> `Fee_Exit = 0.00055`)
- **Цена входа (Entry):** `$79,670.00`
- **Текущий ATR пары:** `0.025` (Роботизированное плечо: `20x`)

#### Пошаговые вычисления ядра калькулятора:

1. **Маржа под сделку (Cost):** `100 / 5 = $20.00`
2. **Общий объем позиции (Value):** `20 * 20 = $400.00`
3. **Размер позиции в монетах (Qty):** `400 / 79,670 = 0.00502 BTC`
4. **Вычисление Стоп Лосса (LONG):**
   `SL = 79,670 * ((1 - 0.02 / 20 - 0.00055) / (1 + 0.00055)) = 79,502.60 USDT`
5. **Вычисление Тейк Профита (LONG):**
   `TP = 79,670 * ((1 + (3 * 0.02) / 20 + 0.00055) / (1 - 0.00055)) = 79,996.90 USDT`
6. **Вычисление Цены Ликвидации (LONG):**
   `Liq = 79,670 * (1 - 1 / 20 + 0.004) = 75,991.60 USDT`

## 🛒 Спецификация и формулы: Спотовый режим (Spot Market)

На спотовом рынке торговое направление принудительно заблокировано в LONG (так как классическая покупка актива не подразумевает маржинальных Шорт-контрактов). Плечо жестко приравнивается к `1x`, а в расчет ядра закладывается спотовая базовая комиссия биржи `Spot Fee = 0.1% (0.001)`.

### 1. Формулы Стоп Лосс (SL) и Тейк Профит (TP) для Спота

Математика учитывает двойное удержание спотовой комиссии (за покупку при входе и за продажу при выходе), а также закладывает скрытый буфер на проскальзывание цены (`Slippage = 0.05%`) при исполнении ордера по рынку (Market).

- **Формула Стоп Лосс (SL):**
  `SL = Price_Entry * (1 - RiskAmount / Cost - SpotFee * 2 - Slippage)`
- **Формула Тейк Профит (TP):**
  `TP = Price_Entry * (1 + (RiskAmount * PR_Ratio) / Cost + SpotFee * 2)`

## 🛠 Пошаговое руководство: Как торговать на Bybit по расчётам терминала

Чтобы совершить сделку на бирже Bybit без ошибок в риск-менеджменте, строго переносите расчетные значения из правой панели терминала в веб-интерфейс или приложение биржи по следующему алгоритму:

### Шаг 1. Настройка режима и плеча на Bybit

1. Откройте торговую пару на Bybit (например, `BTCUSDT` в разделе «Деривативы» или «Спот»).
2. Если вы торгуете фьючерсами, переведите маржу в режим **Изолированная (Isolated)**.
3. Посмотрите на значение в строке **«Рабочее плечо Bybit»** в калькуляторе. Кликните по оранжевой кнопке копирования рядом с ним. На бирже Bybit откройте окно настройки плеча и введите это число вручную для выбранного направления (Лонг или Шорт).

### Шаг 2. Настройка общего объема ордера (Value)

1. В окне выставления ордера на Bybit выберите тип ордера: **Рыночный (Market)** или **Лимитный (Limit)** в соответствии с тем, какой режим нажат в терминале.
2. Переведите ползунок ввода объема на Bybit в режим **«Стоимость» (Value / Номинал в USDT)**, а не «Количество в монетах».
3. Посмотрите на верхнюю строку калькулятора **«Объем в USDT (Value)»**. Нажмите оранжевую кнопку скопировать. Перейдите на Bybit и вставьте скопированное число в поле **«Стоимость»** (или «Объем»).

- _Внимание: Никогда не вводите туда сумму вашего чистого депозита (DEP), иначе вы откроете сделку без учета плеча! Вводить нужно именно высчитанный Total Volume._

### Шаг 3. Выставление защитных ориентиров TP/SL

1. На Bybit поставьте галочку напротив пункта **«TP/SL»** перед открытием позиции.
2. Вернитесь в терминал. Нажмите зеленую кнопку копирования напротив значения **«Тейк Профит»** и вставьте котировку в поле **«Тейк Профит»** на Bybit.
3. Нажмите красную кнопку копирования напротив значения **«Стоп Лосс»** в терминале и вставьте котировку в поле **«Стоп Лосс»** на Bybit.
4. Нажмите кнопку **«Купить/Лонг»** (или «Продать/Шорт») на бирже Bybit для отправки ордера в рынок.

## 🗒 Интерактивное управление журналом ордеров

После того как позиция открыта на Bybit, нажмите кнопку **«Зафиксировать расчет в журнал»** внизу правой панели терминала. Это перенесет параметры сделки в ваш личный дневник.

- **Контроль Безубытка (BU):** Поток WebSocket непрерывно сравнивает текущую рыночную цену с вычисленной ценой окупаемости (`bePrice`), в которую уже заложены все комиссионные издержки на вход и выход. Как только цена пересекает этот уровень, ячейка БУ в таблице загорается яркой неоновой анимацией. Это ваш сигнал: на бирже Bybit можно безопасно передвинуть Стоп Лосс на цену входа — сделка защищена от убытка.
- **Ручное завершение ордера:** Когда вы закрываете позицию на самой бирже (по рынку или по тейку), перейдите в журнал терминала и нажмите крестик (`✕`) в крайней правой колонке строки. Сделка будет приглушена, а кнопка управления исчезнет, переводя запись в статус зафиксированной истории.
