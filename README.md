# 🗒 Bybit Премиум Терминал: Комплексное руководство и Техническая спецификация

Интеллектуальная торговая консоль, разработанная для автоматизации расчёта объёма позиций, риск-менеджмента и ведения динамического журнала ордеров в реальном времени с прямой интеграцией по протоколу WebSocket Bybit V5 Public Stream API.

---

## 📊 1. Математический базис и сквозные примеры расчётов

Торговый движок калькулятора производит прецизионные вычисления на основе динамического и статического учёта комиссионных издержек. Биржа Bybit списывает комиссию дважды: при входе в позицию и при её закрытии (как по стопу, так и по тейку).

Математические алгоритмы терминала закладывают эти издержки непосредственно в цену исполнения, гарантируя, что трейдер потеряет ровно фиксированный процент риска ($RiskAmount$) и заработает чистый профит, строго соответствующий выбранному коэффициенту $P/R Ratio$.

### Торговые константы и системные коэффициенты

- **TAKER_FEE ($TakerFee = 0.00055$ / 0.055%):** Комиссия за исполнение ордера по рынку (Market). Применяется по умолчанию для мгновенного входа по маркету, а также для всех типов Стоп Лосса и Тейк Профита.
- **MAKER_FEE ($MakerFee = 0.00020$ / 0.020%):** Комиссия за исполнение лимитного ордера (Limit). Применяется в расчётах цены входа только при переключении типа ордера в режим "Лимитный".
- **MMR ($MMR = 0.00400$ / 0.40%):** Поддерживающий маржинальный минимум (Maintenance Margin Rate) для бессрочных USDT-контрактов Bybit. Является критическим порогом принудительной ликвидации позиции.
- **SPOT_FEE ($SpotFee = 0.00100$ / 0.10%):** Базовая комиссия спотового рынка за любой тип торговой операции.
- **SPOT_SLIPPAGE ($SpotSlippage = 0.00050$ / 0.05%):** Математическое ожидание рыночного проскальзывания при исполнении спотового маркет-ордера в условиях высокой волатильности.

### Подробный разбор формул фьючерсного рынка (Futures Mode)

#### Сквозной пример для симуляции расчётов фьючерсов (LONG):

- **Баланс ($Balance$):** `100.00` USDT
- **Торговая пара:** `BTCUSDT` (Базовое плечо из конфигурации $Leverage = 20$)
- **Выбранный риск ($RiskPercent$):** `2%` (Выделенный абсолютный риск $RiskAmount = 2.00$ USDT)
- **Цена входа ($EntryPrice$):** `79670.00` USDT
- **Тип ордера:** `Рыночный` (Следовательно, комиссия входа $EntryFee = 0.00055$)
- **Соотношение Риск/Прибыль ($RewardMultiplier$):** `1 : 3` ($RewardMultiplier = 3$)

#### 1. Расчёт маржинальных параметров позиции

Личные средства, резервируемые под залог одной сделки ($Cost$), жестко ограничены одной пятой от общего баланса для обеспечения выживаемости торгового аккаунта при серии системных убытков:
$$Cost = \frac{Balance}{5} = \frac{100.00}{5} = 20.00 \text{ USDT}$$

Общий торговый объём позиции (Value) с учётом кредитного плеча, отображаемый на бирже:
$$Value = Cost \times Leverage = 20.00 \times 20 = 400.00 \text{ USDT}$$

Размер позиции в базовой монете (Qty):
$$Qty = \frac{Value}{EntryPrice} = \frac{400.00}{79670.00} \approx 0.00502 \text{ BTC}$$

Свободный остаток маржинального обеспечения на балансе после открытия сделки:
$$FreeMargin = Balance - Cost = 100.00 - 20.00 = 80.00 \text{ USDT}$$

Количество доступных повторных входов аналогичного объёма до наступления полного маржин-колла:
$$RemainingTrades = \lfloor\frac{FreeMargin}{Cost}\rfloor = \lfloor\frac{80.00}{20.00}\rfloor = 4 \text{ сделки}$$

#### 2. Математика направления LONG (Покупка фьючерсов)

Защитный ордер Stop Loss рассчитывается так, чтобы падение цены актива, умноженное на объём позиции, вместе с торговыми комиссиями за вход и выход дало ровно $2.00$ USDT убытка.

- **Формула Stop Loss (Long):**
  $$SL = EntryPrice \times \frac{1 - \frac{RiskPercent}{100 \times Leverage} - EntryFee}{1 + TakerFee}$$
  _Подстановка данных из Примера №1:_
  $$SL = 79670 \times \frac{1 - \frac{2}{100 \times 20} - 0.00055}{1 + 0.00055} = 79670 \times \frac{1 - 0.001 - 0.00055}{1.00055} = 79670 \times \frac{0.99845}{1.00055} \approx 79502.72 \text{ USDT}$$

- **Формула Take Profit (Long):**
  $$TP = EntryPrice \times \frac{1 + \frac{RewardMultiplier \times RiskPercent}{100 \times Leverage} + EntryFee}{1 - TakerFee}$$
  _Подстановка данных из Примера №1:_
  $$TP = 79670 \times \frac{1 + \frac{3 \times 2}{2000} + 0.00055}{1 - 0.00055} = 79670 \times \frac{1 + 0.003 + 0.00055}{0.99945} = 79670 \times \frac{1.00355}{0.99945} \approx 79996.81 \text{ USDT}$$

- **Формула цены принудительной ликвидации (Liq Long):**
  Уровень, при котором биржа Bybit принудительно закроет позицию, если трейдер не выставит Стоп Лосс.
  $$Liq = EntryPrice \times (1 - \frac{1}{Leverage} + MMR)$$
  _Подстановка данных из Примера №1:_
  $$Liq = 79670 \times (1 - \frac{1}{20} + 0.004) = 79670 \times (1 - 0.05 + 0.004) = 79670 \times 0.954 = 76005.18 \text{ USDT}$$

- **Расчёт цены безубыточности (Break-Even Price Long):**
  Уровень, дойдя до которого позиция окупает обе комиссии торгового круга (вход + выход).
  $$bePrice_{Long} = EntryPrice \times (1 + EntryFee + TakerFee) = 79670 \times (1 + 0.00055 + 0.00055) = 79757.63 \text{ USDT}$$

#### 3. Математика направления SHORT (Продажа фьючерсов)

В режиме короткой позиции прибыль извлекается из падения цены актива, а убыток наносится её ростом. Формулы зеркально инвертируются:

- **Формула Stop Loss (Short):**
  $$SL = EntryPrice \times \frac{1 + \frac{RiskPercent}{100 \times Leverage} + EntryFee}{1 - TakerFee}$$
  _Подстановка данных из Примера №1 (для Шорт-сценария):_
  $$SL = 79670 \times \frac{1 + \frac{2}{2000} + 0.00055}{1 - 0.00055} = 79670 \times \frac{1 + 0.001 + 0.00055}{0.99945} = 79670 \times \frac{1.00155}{0.99945} \approx 79837.36 \text{ USDT}$$

- **Формула Take Profit (Short):**
  $$TP = EntryPrice \times \frac{1 - \frac{RewardMultiplier \times RiskPercent}{100 \times Leverage} - EntryFee}{1 + TakerFee}$$
  _Подстановка данных из Примера №1 (для Шорт-сценария):_
  $$TP = 79670 \times \frac{1 - \frac{3 \times 2}{2000} - 0.00055}{1 + 0.00055} = 79670 \times \frac{1 - 0.003 - 0.00055}{1.00055} = 79670 \times \frac{0.99645}{1.00055} \approx 79343.19 \text{ USDT}$$

- **Формула цены ликвидации (Liq Short):**
  $$Liq = EntryPrice \times (1 + \frac{1}{Leverage} - MMR)$$
  _Подстановка данных из Примера №1 (для Шорт-сценария):_
  $$Liq = 79670 \times (1 + \frac{1}{20} - 0.004) = 79670 \times (1 + 0.05 - 0.004) = 79670 \times 1.046 = 83334.82 \text{ USDT}$$

- **Цена безубыточности (Break-Even Short):**
  $$bePrice_{Short} = EntryPrice \times (1 - EntryFee - TakerFee) = 79670 \times (1 - 0.00055 - 0.00055) = 79582.36 \text{ USDT}$$

### Подробный разбор формул спотового рынка (Spot Mode)

На спотовом рынке кредитное плечо принудительно равно 1 ($Leverage = 1$), а шорт-позиции полностью заблокированы интерфейсом. Из расчётов исключается поддерживающая маржа ($MMR$), так как спотовые активы принадлежат трейдеру на праве собственности и не могут быть ликвидированы биржей по рыночной стоимости.

#### Сквозной пример для симуляции расчётов спота:

- **Баланс ($Balance$):** `500.00` USDT
- **Залоговая маржа сделки:** $Cost = \frac{500.00}{5} = 100.00$ USDT
- **Выбранный риск ($RiskPercent$):** `1%` от общего депозита
- **Абсолютный риск в деньгах ($RiskAmount$):** $5.00$ USDT
- **Цена входа ($EntryPrice$):** `100.00` USDT
- **Тип ордера:** `Рыночный` (Следовательно, применяется проскальзывание $SpotSlippage = 0.0005$)

#### 1. Расчёт защитных и целевых уровней спота

- **Формула Stop Loss (Spot):**
  Защитный уровень рассчитывается с учётом двойной спотовой комиссии (за покупку и последующую экстренную продажу актива) и математического ожидания проскальзывания рыночного стакана:
  $$SL = EntryPrice \times (1 - \frac{RiskAmount}{Cost} - SpotFee \times 2 - SpotSlippage)$$
  _Подстановка данных из примера:_
  $$SL = 100 \times (1 - \frac{5.00}{100.00} - 0.001 \times 2 - 0.0005) = 100 \times (1 - 0.05 - 0.002 - 0.0005) = 100 \times 0.9475 = 94.75 \text{ USDT}$$

- **Формула Take Profit (Spot):**
  Целевой уровень рассчитывает цену продажи так, чтобы покрыть спотовые комиссии торгового круга и зафиксировать чистую прибыль, равную размеру риска, умноженному на коэффициент математического ожидания:
  $$TP = EntryPrice \times (1 + \frac{RiskAmount \times RewardMultiplier}{Cost} + SpotFee \times 2)$$
  _При коэффициенте 1 : 3 ($RewardMultiplier = 3$):_
  $$TP = 100 \times (1 + \frac{5.00 \times 3}{100.00} + 0.001 \times 2) = 100 \times (1 + 0.15 + 0.002) = 100 \times 1.152 = 115.20 \text{ USDT}$$

- **Цена безубыточности (Break-Even Price Spot):**
  Уровень окупаемости спотовой позиции с учётом двойного списания торгового сбора и проскальзывания:
  $$bePrice_{Spot} = EntryPrice \times (1 + SpotFee \times 2 + SpotSlippage) = 100 \times (1 + 0.002 + 0.0005) = 100.25 \text{ USDT}$$

### Динамическая шкала безопасности ликвидации (Liquidation Safety)

Для предотвращения ситуаций, когда биржевой механизм ликвидации срабатывает раньше, чем цена доходит до системного Стоп Лосса (что приводит к потере всей маржи $Cost$ вместо расчётного риска $RiskAmount$), терминал непрерывно вычисляет коэффициент безопасности положения ордера:

$$SafetyPercent = \max\left(0, \min\left(100, \left(1 - \frac{|EntryPrice - SL|}{|EntryPrice - Liq|}\right) \times 100\right)\right)$$

На основе полученного значения интерфейс активирует один из четырёх встроенных режимов визуального информирования в реальном времени:

| Процент безопасности                 | Сигнал советника в интерфейсе                 | Описание текущего рыночного состояния                                                                                                                 |
| :----------------------------------- | :-------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **< 25%** _(Или если SL дальше Liq)_ | 🛑 АЛЕРТ: Ликвидация ближе Стопа! Убавь риск! | Критическая конфигурация. Позиция будет принудительно закрыта биржей с потерей всей маржи до того, как сработает Стоп Лосс. Необходимо снизить плечо. |
| **25% – 59%**                        | ⚠️ ВНИМАНИЕ: Опасная зона, снизь плечо        | Повышенный риск выноса маржинального обеспечения. Запас хода цены слишком мал для текущей волатильности ATR.                                          |
| **60% – 84%**                        | ⚡ В НОРМЕ: Запас волатильности учтен         | Стандартное рабочее положение ордеров. Случайный рыночный шум и микроспреды защищены расчётным буфером.                                               |
| **85% – 100%**                       | 🟢 ИДЕАЛЬНО: Полная защита от ATR выноса      | Максимальный уровень безопасности. Позиция полностью защищена от случайных импульсных шпилек и манипуляций ликвидностью.                              |

## ➡️ 2. Пошаговый эксплуатационный регламент трейдера

### Этап А: Инициализация и настройка риск-параметров

1. Перейдите к виджету управления **DEP** в правом верхнем углу интерфейса. Введите текущий баланс маржинального обеспечения вашего торгового аккаунта Bybit в поле ввода.
2. Выберите фиксированный процент потери капитала на одну сделку с помощью кнопок реактивного переключения риска:
   - **1%** — консервативный торговый режим (минимальная просадка).
   - **2%** — умеренный торговый режим (стандартный рабочий риск).
   - **3%** — агрессивный торговый режим (максимальная нагрузка на депозит).

### Этап Б: Конфигурация торговой сессии

1. Переключите режим рынка на левой панели управления:
   - **Фьючерсы** — активирует торговлю бессрочными контрактами с использованием автоматического плеча в направлениях Лонг и Шорт.
   - **Спот** — переводит терминал в режим чистой покупки базового актива без использования заёмных средств. Блок выбора направления "Шорт" при этом скрывается из DOM-дерева через класс `.fade-out`.
2. Задайте тип ордера исполнения:
   - **Лимитный** — расчёт параметров под отложенный ордер (сниженная базовая комиссия Bybit Maker).
   - **Рыночный** — расчёт под мгновенный вход по текущему стакану биржи (включает комиссию Taker и проскальзывание).
3. Установите целевое математическое соотношение Риск/Прибыль в селекторе **P/R Ratio** (системное значение по умолчанию — **1:3**).

### Этап В: Инжекция котировок в один клик через живой информер

1. Модуль `bybit-live-informer` автоматически подключается к WebSocket-каналам биржи (`orderbook.1` и `tickers`) и транслирует котировки в реальном времени.
2. Синхронизируйте калькулятор с текущим состоянием стакана биржи Bybit с помощью интерактивных кликов по информеру:
   - **Клик по центральной живой цене** — вычисляет среднюю цену (Mid Price) стакана, автоматически подставляет полученное число в инпут "Цена входа", копирует его в буфер обмена операционной системы и осуществляет мгновенный перерасчёт всех параметров.
   - **Клик по значению Ask** — мгновенно инжектирует в калькулятор лучшую цену продажи (верхняя граница спреда).
   - **Клик по значению Bid** — мгновенно инжектирует в калькулятор лучшую цену покупки (нижняя граница спреда).

### Этап Г: Валидация и перенос параметров на Bybit

1. Проверьте показания индикатора под ценой ликвидации на правой панели. При появлении предупреждения **🛑 АЛЕРТ** (цена ликвидации находится ближе, чем расчетный Стоп Лосс) категорически запрещено открывать сделку. Снизьте риск кнопкой до 1% или переключите пару.
2. При успешной валидации (зелёная шкала **🟢 ИДЕАЛЬНО**) перенесите параметры ордера на биржу:
   - Кликните по оранжевой кнопке копирования рядом с полем **Объем в USDT (Value)**. Вставьте скопированное значение на Bybit в поле «Стоимость» (или «Количество USDT»).
   - Установите на ползунке плеча биржи Bybit значение, строго соответствующее полю **Рабочее плечо Bybit**.
   - Скопируйте и перенесите в block TP/SL на бирже точные ценовые значения **Тейк Профит** и **Стоп Лосс**.
   - Откройте сделку кнопкой Купить или Продать в терминале биржи.

### Этап Д: Сопровождение и архивация сделки в журнале ордеров

1. В калькуляторе нажмите кнопку **«Зафиксировать расчет в журнал»**. Запись мгновенно сохранится в энергонезависимую память LocalStorage и отобразится в нижней таблице.
2. WebSocket-клиент терминала начнёт в фоне сопоставлять живую цену актива с ценой безубытка (**БУ**) зафиксированного ордера. При пересечении этого уровня ячейка БУ в таблице активирует неоновую анимацию `be-reached-glow`. При её появлении перенесите Стоп Лосс на бирже в точку входа.
3. После фактического закрытия сделки на бирже нажмите кнопку **✕** в крайней ячейке строки журнала. Подтвердите действие во всплывающем окне — строка приглушит свою яркость (`opacity: 0.35`) и перейдёт в архивный статус. При необходимости выгрузите историю торгов через кнопку **«Экспорт CSV»**.
